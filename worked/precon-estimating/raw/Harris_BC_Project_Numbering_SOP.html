This document establishes the standard operating procedure for creating and numbering projects in BuildingConnected across all Harris Associates offices. Consistent numbering ensures projects are traceable from first opportunity through award, and enables accurate reporting across pursuits, estimates, and active bids.

Section 01
The Standard Number Format
26-0001-LV-BID
Year
Two-digit fiscal year the project was created in BuildingConnected.
Sequence
Four-digit sequential number, zero-padded, unique per office per year per type.
Office Code
Two-letter code for the originating Harris office. LV = Las Vegas. AZ = Arizona.
Project Type
Three-letter code indicating the current phase or purpose of the project record.

Section 03
Project Type Codes & When to Use Them
Code Phase Name Description When to Create BC Setup Notes
OPP
Opportunity
 Early-stage pursuit. Client has made contact or issued an RFQ/RFP but no drawings or scope documents are available yet. No formal estimate has been started. Create when Harris decides to formally pursue a project and wants to track it in BC. isForBudgeting: No
No bid packages yet. Notes field for pursuit status.
ROM
Rough Order of Magnitude
 High-level ballpark cost estimate produced with minimal documents — typically square footage, project type, and comparable project data. Accuracy range: ±30–50%. Create when a client requests a quick number before committing to full design or when Harris needs a go/no-go threshold. isForBudgeting: Yes
Enter single lump-sum cost. Note basis of estimate in description.
OC
Opinion of Cost
 Formal cost opinion prepared from schematic or design development documents. More detailed than a ROM but not a full sub-solicited bid. Typically delivered to owner/architect as a design tool. Accuracy range: ±15–25%. Create when Harris is engaged by owner or architect to validate design budget before construction documents are complete. isForBudgeting: Yes
Use cost line items by division. Document scope assumptions clearly.
EST
Estimate
 Detailed internal estimate prepared from construction documents (50–100% CDs). May or may not involve subcontractor solicitation. Used to establish Harris's internal budget before going to bid or entering GMP negotiations. Create when CDs are sufficient to support a trade-by-trade takeoff and Harris is developing its own number ahead of a formal bid. isForBudgeting: Yes
Create bid packages by trade. May solicit select subs for budget pricing.
BID
Active Bid
 Formal competitive or negotiated bid process. Harris is actively soliciting subcontractor bids across all trades, managing a bid due date, and preparing a formal proposal for submission to the owner. Create when a bid due date is set and Harris is formally soliciting subcontractors in BC. isForBudgeting: No
Set bid due date. Create bid packages per trade. Invite subs. Seal bids if required.
AWD
Post-Bid / Awarded
 Harris has been awarded the project or is in final GMP/contract negotiations. The BC project record transitions to an awarded state and becomes the reference point for the executed subcontract solicitation. Update status when Harris receives a formal Letter of Intent, executed contract, or NTP. awarded: true
Update project status to awarded. Link to ACC/Forma project if applicable.

Section 05
Operating Rules
  • R-01 Every project entered in BuildingConnected must receive a number. Unnumbered projects are not searchable, reportable, or traceable. No exceptions.
  • R-02 Numbers are assigned at creation and never changed. If a project evolves from a ROM to a BID, do not renumber. Instead, update the project description to reflect the current phase. The original number is permanent.
  • R-03 Sequences are tracked per year, per office, per type. 26-0001-LV-BID and 26-0001-AZ-BID can coexist. 26-0001-LV-BID and 26-0001-LV-OC can coexist. No two projects within the same year/office/type combination may share a number.
  • R-04 The Preconstruction team owns the number register. Jeff Contenta or a designated Preconstruction coordinator assigns new numbers. Do not self-assign numbers without confirmation from Preconstruction.
  • R-05 Projects that do not advance are not deleted. Mark them inactive or close them in BC with a note. The number is retired, not reused.
  • R-06 The project name in BC should match the name used in all client-facing documents, emails, and QuickBooks. Avoid abbreviations or internal shorthand in the official name field.
  • R-07 Awarded projects must be linked to the corresponding ACC / Forma project once mobilization begins. The BC number becomes the reference ID across both platforms.
  • R-08 The year in the number reflects the year the BC record was created, not the year construction begins. A project created in December 2026 that constructs in 2027 is still numbered 26-####-XX-XXX.
