This document defines the standard folder structure created in SharePoint for every project entered in BuildingConnected. The structure is created at the OPP phase and remains constant as the project advances through all preconstruction phases.

Section 01
Project Folder Naming
Folder Name Format
26-0001-LV – Project Name
The permanent identifier (YY-####-XX) is used as the folder name. The phase status code is never included in the folder name — it is tracked in BuildingConnected only.
Examples
26-0001-LV – Downtown Summerlin Restaurant
26-0002-LV – The Cliffs Dual Brand Hotel
26-0001-AZ – Scottsdale Restaurant TI
Section 02
Standard Folder Structure
This structure is created at OPP and never reorganized. Folders that are not yet needed simply remain empty as the project advances. All phases — OC, BGT, BID, and AWD — are accommodated within this single structure.
